# Freight Rate ML Assessment - Final Report

## Validation Strategy & Data Split

The labeled dataset (`train-test.csv`) spans from January 1, 2025, to October 31, 2025. The unlabeled final evaluation dataset (`validation.csv`) spans from November 1, 2025, to December 31, 2025.

### Key Findings:
- **Temporal Drift:** Freight rates have seasonal and temporal trends. Evaluating on a random split would overestimate performance due to data leakage.
- **Unseen Categories:** The validation set contains 8 pickup/delivery cities that do not appear in the training data. The model must handle missing levels gracefully.
- **Missing Data:** The `weight` and `market_index` columns contain missing values, which were addressed using median imputation.

### Validation Approach:
Given the temporal nature of the final evaluation set (Nov-Dec), a **time-based validation split** was employed:
- **Training Set:** January 1, 2025 – September 30, 2025
- **Validation Set:** October 1, 2025 – October 31, 2025

This simulates the real-world deployment scenario where we use historical data to predict future rates. 

### Modeling:
A Gradient Boosting model (LightGBM) was chosen because it handles missing values natively, is robust to categorical features without extensive one-hot encoding, and manages non-linear relationships well (such as `distance` vs. `posted_rate`). Features included temporal extractions (month, day of week, day of year), interaction terms (distance * weight), and frequency encoded categorical variables.
